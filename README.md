# Mark

Bookmark management programme and GraphQL server. WIP.

Currently only supports *adding* bookmarks, which is obviously inadequate.

You can run it as a standalone CLI application and import bookmarks from your browsers...
at least the ones I happen to have installed, and therefore know where are located.

See [tiara](https://github.com/lfknudsen/tiara) for a frontend that allows the user to add bookmarks.
